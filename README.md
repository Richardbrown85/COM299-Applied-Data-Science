# COM299 Applied Data Science

Applied Data Science project using the Department for Transport STATS19 road safety dataset.

## Stakeholder Brief

SB4 – Insurance Analytics Team

**Question:** Which vehicle and circumstantial factors are associated with casualty severity, and how strong is the evidence for each?

## Current Status

Project setup complete. Unit of analysis still to be confirmed.

## Project Structure

- `data/raw/` - original source data
- `data/processed/` - cleaned and processed data
- `notebooks/` - analysis notebooks
- `src/` - reusable Python code
- `dashboard/` - dashboard files
- `docs/` - source and data quality documentation
- `outputs/` - figures and tables
